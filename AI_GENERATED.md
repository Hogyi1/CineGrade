## 5. Maintenance Protocol

Whenever an AI assistant generates new artifacts:
1. Add standard tagging at the top of the file:
   - Full Java file: `// [AI-GENERATED]` (placed on line 1)
   - Specific Java method: `// [AI-GENERATED METHOD]` (placed immediately above the method signature)
   - Specific Java constant/table strings: `// [AI-GENERATED TABLE STRINGS]` (placed above the constant declarations)
   - FXML file: `<!-- [AI-GENERATED] -->` (placed directly below the `<?xml ...?>` line)
   - CSS file: `/* [AI-GENERATED] */` (placed on line 1)
2. Append the new entry to this `AI_GENERATED.md` file under the appropriate section.
3. Preserve all existing `import` statements without modification.
